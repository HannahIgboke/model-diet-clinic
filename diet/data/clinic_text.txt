def word_counts(path):
    counts = {}
    with open(path, encoding="utf-8") as f:
        for line in f:
            for word in line.lower().split():
                counts[word] = counts.get(word, 0) + 1
    return sorted(counts.items(), key=lambda kv: kv[1], reverse=True)

A large language model is mostly weights. When people say a model has seven billion parameters, they mean it is made of seven billion numbers. If each number is stored with sixteen bits, that is two bytes per number and about fourteen gigabytes in total. The size of the model on disk is simply the number of parameters multiplied by the number of bytes used to store each one. Change either of those and the model gets lighter or heavier.

class Stack:
    def __init__(self):
        self.items = []

    def push(self, item):
        self.items.append(item)

    def pop(self):
        if not self.items:
            raise IndexError("pop from empty stack")
        return self.items.pop()

Quantization means storing numbers with less precision. Instead of keeping each weight as a sixteen bit number, we round it to one of a small set of values that fit in eight bits or even four bits. Most weights in a large model are small and clustered around zero, so careful rounding loses surprisingly little information. A model quantized to four bits can be about a quarter of its original size and still answer most questions well.

Pruning takes a different approach. Instead of making every number smaller, it removes some numbers entirely. If many weights are close to zero, perhaps they are not doing much, and setting them to exactly zero changes the output only slightly. The difficulty is that a matrix full of zeros still takes up the same space unless the software knows how to skip them. Removing whole layers avoids that problem, because a missing layer genuinely takes no space at all.

Distillation trains a smaller student model to imitate a larger teacher. The student does not only learn the correct answers; it learns how confident the teacher is about every possible answer. When the teacher thinks the next word is probably "river" but might be "road" or "market", the student learns those preferences too. This extra information helps a small model learn far more from each example than it would from the correct answer alone.
